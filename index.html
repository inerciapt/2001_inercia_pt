General rules:

All entering contributions must not have been released before. All entries are subjected to pre-jury. The organizers reserve the right to distribute your entry freely.

Demo/Intro compo extra rules:

- If there aren't enough entries to from two competitions, the organization will move the Intro compo into the Demo compo being all entries annouced in their categories.
- If you wish to enter the competition with a contribution that does NOT run under Win M.E. contact the organizers in advance so that your contribution may be shown at the party.

Tracked / "High-quality" Music extra rules:

- If there aren't enough entries to form two competitions, the organization will join these two in one competition being all entries annouced in their categories.

Party machine:

- Pentium 1 GHz
- 128 Mb RAM
- Win M.E.
- SoundBlaster Live
- NVidia GeForce 2 MX
- DirectX 8.1 / OpenGL 1.1

Demo rules:

- Maximum duration: 10 minutes
- Maximum ZIP file size: 10 Mb
- Must not write to disk
- Should not switch videomodes during presentation. This may take a while in a projector and subsequently parts may not be shown.
- Must play sound

Intro rules:

- Maximum duration: 5 minutes
- Maximum ZIP file size: 128 Kb (The classic 64 kb intro compo will be "slighlty" modified so that not too much time is spent compressing the actual intro but instead leave some more time for actual effects, sound, etc.)

Gfx rules:

- Entries will be shown using latest ACDsee
- Maximum resolution is not yet set due to projector problems. Should not be over 800 x 600 x 24bit though.
- Pictures must NOT be signed
- At least 4 pictures will have to be turned in along with the final version displaying the creation process. These are only for pre-judging display.

Video rules (wild demo):

- Maximum durantion: 10 minutes
- Maximum file size (no ZIP's): 100 Mb
- Formats: AVI, MPEG and DivX
- Videos must be delivered in a CD along with codecs. CD's will NOT be returned.

Tracked music rules:

- Maximum duration: 5 minutes (will be faded out if any longer)
- Maximum ZIP file size: 2 Mb
- Formats: IT, XM, S3M, MOD

"High-quality" music rules:

- Maximum duration: 5 minutes (will be faded out if any longer)
- Maximum ZIP file size: 6 Mb
- Formats: MP3, OGG, WMA

Web rules:

- Maximum ZIP size: 1 Mb
- Formats: HTML page with or without Flash, or just Flash (may be a small demo/intro)
